# 🔮 ജാതകംGPT — AI ജ്യോത്സ്യൻ (Brahmasree Biju)

> **“മുഖം സ്കാൻ ചെയ്യൂ. ഭാവി കേൾക്കൂ. വിശ്വസിക്കരുത്.”**

## 💡 The Problem (that doesn't exist)
In a world full of high-tech AI agents solving complex problems, people in Kerala are still consulting neighbourhood astrologers to ask whether their *Chovva Dosham* (Mars defect) is blocking their US visa, or why their crush left them on "Seen" for 14 hours. 

Nobody asked for an AI that combines client-side computer vision with eccentric Malayalam astrologer commentary to roast your career choices, romantic failures, and Swiggy addiction.

---

## ⚡ The Solution (that nobody asked for)
Meet **Brahmasree Biju** — Kerala's premier AI ജ്യോത്സ്യൻ (Cyber-Astrologer). 

**ജാതകംGPT** turns your webcam into a high-tech "Forehead Chakra Scanner" that:
1. **Tracks Your Face in Real-Time**: Client-side face detection powered by Google MediaPipe locks onto your forehead chakra with retro sci-fi reticles.
2. **Speaks Aloud Through Speakers**: Brahmasree Biju talks to you live in natural Malayalam voice (`ml-IN-MidhunNeural`) while scanning your face and inferring your expressions (smiling, tilted head, or serious gaze).
3. **Delivers 5 Multi-Foretellings per Reading**:
   - 💼 **കരിയർ & തൊഴിൽ ജാതകം** (Satirical Career Verdict & Punchline)
   - 💘 **പ്രണയ / വിവാഹ ജാതകം** (Romance, Matrimony & WhatsApp Scene Forecast)
   - 💰 **ധനയോഗം & സമ്പാദ്യം** (Wealth, EMI, Swiggy & Spending Forecast)
   - 🍕 **ജീവിതശൈലി & ആരോഗ്യം** (Daily Routine, Reels & Health Forecast)
   - 🧘‍♂️ **ബിജുവിന്റെ പരിഹാരം** (Absurd Astrological Remedy / Pariharam)
4. **16 Iconic Kerala Satirical Archetypes**: Software Engineer, Government Officer, Startup CEO, NRI Gulf Uncle, PSC Aspirant, Instagram Influencer, Troll Page Admin, Autorickshaw Pilot, Doctor, High Court Lawyer, UI/UX Designer, Crypto Trader, Kalyana Broker, Food Vlogger, Thattukada Master Chef, and Professional Sleeper.
5. **Interactive Section-by-Section Audio**: Click **[ 🔊 കേൾക്കാം ]** on any card to hear Biju read that specific foretelling with synchronized visual card highlighting!

---

## 🛠️ Tech Stack

- **Backend**: Python 3, FastAPI, Uvicorn
- **Voice Synthesis**: Microsoft Edge-TTS (`ml-IN-MidhunNeural` with custom prosody tuning)
- **Computer Vision**: Google MediaPipe Face Detection (100% browser-side, zero photo uploads)
- **Frontend**: HTML5, Tailwind CSS (Neo-brutalist styling), Web Audio API
- **Audio Engine**: Pre-rendered local cache for instant zero-latency speech

## 🚀 Quick Start

### 1. Clone or Download the Repository
```bash
git clone https://github.com/<your-username>/jathakam-gpt.git
cd jathakam-gpt
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
```bash
python main.py
```
*(Or double-click `run.bat` on Windows!)*

### 4. Open in Browser
Visit **[http://localhost:8000](http://localhost:8000)**
